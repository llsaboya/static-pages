MODULE 3 · N1 · Cognitive LoadPage 2 of 6

Cognitive load is split into intrinsic, extrinsic, and germane effort.

[Abbreviated example] The same screen poses different demands for each professional. Intrinsic load stems from the material itself. Extrinsic load stems from presentation. The project directly controls the latter.

DEFINITION · Schema

Schema — a stored mental structure that the professional processes as a single unit.

An experienced professional retrieves the schema as a single unit. A novice processes every element individually. The same task imposes higher load on novices due to simultaneous unintegrated elements.

COUNTERPOINT · de JongThe review questions whether all three loads can be measured independently.— de Jong, 2010
Split-Attention Effect: The Case of Displaced Labels

A diagram sits on one screen while its labels reside on another. The professional must hold each label in working memory while scanning for the corresponding component. Place each label directly adjacent to its element.

LANDSCAPE-PLACEHOLDER
FIG · N1 · B6 · SME-S01-02-1

Caption: Which load fits into working memory? Intrinsic and extrinsic loads add up.

By overlaying labels directly onto the diagram, split attention is eliminated, freeing up mental capacity to process relationships.
