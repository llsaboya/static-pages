MODULE 3 · 3.2 · Three kinds of loadPage 2 of 5

Load comes in three kinds: the material, the presentation, and the effort to learn.

Governing claim of this page

Cognitive load theory divides the demand on working memory into three kinds. Intrinsic load comes from the material itself. Extraneous load comes from the way the material is presented. Germane load is the effort a learner spends building schemas. Instruction can change the second directly. The first depends on the material and on what the learner already knows.

Definition · Element interactivity
The number of items a learner must hold and relate at the same time because they depend on each other. One vocabulary word has low interactivity. A grammar rule that links tense, subject, and mood has high.

Intrinsic load rises with element interactivity (the number of items a learner must relate at once). It also depends on prior knowledge. An expert holds a familiar pattern as one unit. A novice holds each part separately. The same task therefore loads a novice more than an expert.

Depth · Split attention

A diagram sits on one screen. Its labels sit in a paragraph below. The learner scrolls between them and holds each label in memory while looking for its part. The task did not get harder. The layout added load. Place each label on the diagram, beside the part it names.

Germane load entered the theory in 1998. It names the effort that goes into building schemas. The design aim follows from the three kinds: remove extraneous load first, so capacity remains for the effort of learning.

Counterpoint · de Jong (2010)
Ton de Jong's 2010 review questions whether the three loads can be defined and measured apart. Critics report that germane and extraneous load are hard to distinguish. The design advice on extraneous load is less contested.
